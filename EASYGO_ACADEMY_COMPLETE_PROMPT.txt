## APLICACIÓN MÓVIL DE APRENDIZAJE DE INGLÉS PARA HISPANOHABLANTES

---

## DESCRIPCIÓN GENERAL DEL PROYECTO

EasyGo Academy es una aplicación móvil Progressive Web App (PWA) diseñada específicamente para hispanohablantes que viven en Estados Unidos y necesitan aprender inglés de manera práctica y conversacional. La aplicación debe funcionar predominantemente en modo offline (arquitectura 80% local / 20% nube) para optimizar recursos y permitir aprendizaje sin conexión a internet.

**Plataformas objetivo:**
- Aplicación Android (compilada con Capacitor)
- Panel de administración web (accesible desde navegador)
- PWA con funcionalidad offline completa

**Arquitectura de datos:**
- 80% de la lógica corre en el dispositivo móvil
- 20% requiere conexión a la nube o base de datos
- Almacenamiento local con IndexedDB para funcionamiento offline
- Sincronización automática cuando hay conexión disponible

## SECCIÓN 1: REQUISITOS TÉCNICOS FUNDAMENTALES

### 1.1 Stack Tecnológico

Utiliza las siguientes tecnologías y configura el proyecto en consecuencia:

```
Framework principal: React 18+ con TypeScript
Sistema de construcción: Vite 6.0
Framework CSS: Tailwind CSS 3.4
Gestión de estado: Zustand con persistencia local
Base de datos local: IndexedDB (mediante idb-react)
Backend cloud: Supabase (PostgreSQL + Auth + Storage)
Autenticación: Supabase Auth
Compilación Android: Capacitor 8.3
Comunicación: PWA (Service Workers)
UI Components: Lucide React icons + Componentes custom
Gráficos: Recharts (para dashboards de progreso)
Traducción i18n: i18next + react-i18next
```

```typescript

interface Lesson {

  masteryLevel: number; // 0-5
  lastReviewed?: string;
  nextReview?: string;
  timesCorrect: number;
  timesIncorrect: number;
}

// Estructura de progreso del usuario
interface UserProgress {
  lessonId: string;
  completed: boolean;
  score: number;
  timeSpentSeconds: number;
  completedAt?: string;
}

// Estructura de progreso diario
interface DailyProgress {
  date: string;
  lessonsCompleted: number;
  xpEarned: number;
  minutesPracticed: number;

  wordsLearned: number;
}
```

### 2.2 Stores de Zustand

Crea stores separados para cada dominio funcional:

```typescript
// Auth Store - usuario, autenticación, configuración
// Progress Store - progreso de lecciones, progreso diario
// Vocabulary Store - palabras aprendidas, mastery
// Gamification Store - XP, rachas, badges, achievements, missions
// Community Store - posts, comentarios, grupos
// App Store - estado online/offline, sync status, idioma
```

Cada store debe usar `persist` con `createJSONStorage(() => localStorage)` para persistencia local.

## SECCIÓN 4: SISTEMA DE GAMIFICACIÓN

### 4.1 Sistema de XP y Niveles

```
Cálculo de nivel:
- Nivel = floor(XP / 1000) + 1
- XP para siguiente nivel = 1000

Recompensas de XP:
- Completar lección: 100-250 XP (según duración)
- Práctica de conversación: 30-100 XP
- Check-in diario: 10 XP
- Completar misión diaria: 20-50 XP
- Desbloquear logro: 100-500 XP
```

### 4.2 Sistema de Rachas

```
Visualización:
- Emoji de llama que crece con la racha

Misiones diarias:
- Completar 1 lección
- Practicar 5 minutos de conversación
- Aprender 10 palabras nuevas
- Mantener racha activa

Protección de racha:
- Streak freeze (comprable con XP)
- Grace period de 1 día
```

## SECCIÓN 13: FUNCIONALIDADES ESPECIALES

### 13.1 Navegación

```
Bottom Navigation (solo en móvil):
- Inicio (casa)
- Lecciones (libro)
- Práctica (mensaje)
- Comunidad (usuarios)
- Progreso (gráfico)

Parámetros de navegación:
- activeTab: string
- onTabChange: (tab: string) => void
```

### 13.2 Admin Mode

```
Acceso al panel admin:
- Botón en header o settings
- Cambia isAdminMode a true
- Renderiza AdminDashboard completo

AdminDashboard:
- Layout con sidebar (64px de ancho)
- Navegación por secciones
- Contenido principal (flex-1)
```

## NOTAS IMPORTANTES PARA LA IMPLEMENTACIÓN

### Requisitos de estilo:
- Sigue exactamente los colores de marca (gradiente púrpura-naranja)
- Usa tipografía Inter para texto, Poppins para logo, Dancing Script para "Academy"
- Implementa border-radius consistente (8px-24px según componente)
- Mantén espaciado consistente con múltiplos de 8px

### Responsividad:
- Max-width de 448px (lg breakpoint) para contenido móvil
- Diseño responsive que funcione en móvil y desktop
- Admin dashboard optimizado para desktop

### Performance:
- Lazy loading para componentes pesados
- Code splitting por rutas
- Imágenes optimizadas
- CSS minificado en producción

### Accesibilidad:
- Contraste de colores WCAG AA
- Tamaño de targets mínimo 44px
- Navegación por teclado
- Texto alternativo en imágenes
