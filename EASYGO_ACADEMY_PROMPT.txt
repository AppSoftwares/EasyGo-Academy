# PROMPT PARA GITHUB COPILOT - EASYGO ACADEMY

## CONTEXTO GENERAL

EASYGO ACADEMY es una aplicación móvil de aprendizaje de inglés diseñada específicamente para hispanohablantes que viven en Estados Unidos. La aplicación debe seguir una arquitectura frontend-heavy donde el 80% de la lógica corre en el dispositivo móvil y solo el 20% requiere conexión a la nube o base de datos, optimizando el rendimiento y permitiendo funcionalidad offline completa.

## SECCIÓN 6: ESTRUCTURA DE BASE DE DATOS

### 6.1 Database Schema (Supabase/PostgreSQL)

```sql
-- Users Table
CREATE TABLE users (
  id UUID PRIMARY KEY REFERENCES auth.users(id),
  email VARCHAR(255) UNIQUE NOT NULL,
  display_name VARCHAR(100),
  avatar_url TEXT,
  level VARCHAR(20) DEFAULT 'beginner',
  total_xp INTEGER DEFAULT 0,
  current_streak INTEGER DEFAULT 0,
  longest_streak INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Lessons Table
CREATE TABLE lessons (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  level VARCHAR(20) NOT NULL,
  category VARCHAR(50) NOT NULL,
  title VARCHAR(255) NOT NULL,
  description TEXT,
  content JSONB NOT NULL,
  duration_minutes INTEGER,
  xp_reward INTEGER DEFAULT 100,
  order_index INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);

-- User Progress Table
CREATE TABLE user_progress (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  lesson_id UUID REFERENCES lessons(id),
  completed BOOLEAN DEFAULT FALSE,
  score INTEGER,
  time_spent_seconds INTEGER,
  completed_at TIMESTAMP,
  UNIQUE(user_id, lesson_id)
);

-- Vocabulary Table
CREATE TABLE vocabulary (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  word VARCHAR(255) NOT NULL,
  translation TEXT NOT NULL,
  phonetic VARCHAR(255),
  audio_url TEXT,
  category VARCHAR(50),
  difficulty VARCHAR(20)
);

-- User Vocabulary (learned words)
CREATE TABLE user_vocabulary (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  vocabulary_id UUID REFERENCES vocabulary(id),
  mastery_level INTEGER DEFAULT 0,
  last_reviewed TIMESTAMP,
  next_review TIMESTAMP,
  times_correct INTEGER DEFAULT 0,
  times_incorrect INTEGER DEFAULT 0
);

-- Achievements Table
CREATE TABLE achievements (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(100) NOT NULL,
  description TEXT,
  icon_url TEXT,
  xp_reward INTEGER,
  criteria JSONB
);

-- User Achievements
CREATE TABLE user_achievements (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  achievement_id UUID REFERENCES achievements(id),
  unlocked_at TIMESTAMP DEFAULT NOW()
);

-- Community Posts
CREATE TABLE community_posts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  title VARCHAR(255),
  content TEXT NOT NULL,
  category VARCHAR(50),
  likes_count INTEGER DEFAULT 0,
  comments_count INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Daily Missions
CREATE TABLE daily_missions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title VARCHAR(255) NOT NULL,
  description TEXT,
  xp_reward INTEGER,
  mission_type VARCHAR(50),
  target_value INTEGER
);

-- User Daily Progress
CREATE TABLE user_daily_progress (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  date DATE NOT NULL,
  lessons_completed INTEGER DEFAULT 0,
  xp_earned INTEGER DEFAULT 0,
  minutes_practiced INTEGER DEFAULT 0,
  missions_completed INTEGER DEFAULT 0,
  UNIQUE(user_id, date)
);

-- User Badges
CREATE TABLE user_badges (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  badge_type VARCHAR(50) NOT NULL,
  earned_at TIMESTAMP DEFAULT NOW()
);
```

## SECCIÓN 7: API ENDPOINTS

### 7.1 API Structure

```
API Routes:
  /api/auth
    ├── POST /register - Create new user
    ├── POST /login - User authentication
    ├── POST /logout - End session
    └── POST /refresh - Refresh token

  /api/users
    ├── GET /profile - Get user profile
    ├── PUT /profile - Update profile
    ├── GET /stats - Get user statistics
    └── GET /achievements - Get achievements

  /api/lessons
    ├── GET / - List all lessons
    ├── GET /:id - Get lesson details
    ├── POST /:id/progress - Update progress
    └── GET /categories - Get lesson categories

  /api/vocabulary
    ├── GET / - Get user vocabulary
    ├── POST / - Add new word
    ├── PUT /:id - Update mastery
    └── DELETE /:id - Remove word

  /api/community
    ├── GET /posts - List posts
    ├── POST /posts - Create post
    ├── GET /posts/:id - Get post details
    └── POST /posts/:id/comments - Add comment

  /api/sync
    ├── POST /upload - Upload offline data
    ├── GET /download - Download updates
    └── GET /status - Sync status

  /api/ai
    ├── POST /conversation - AI conversation
    ├── POST /pronunciation - Pronunciation check
```
