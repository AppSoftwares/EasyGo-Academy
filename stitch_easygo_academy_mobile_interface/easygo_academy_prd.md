# EasyGo Academy - Technical Specification & Requirements

## Core Principles
- 80% Local / 20% Cloud (Offline-first architecture).
- Data Persistence: IndexedDB (Local) + Supabase (Cloud).
- State Management: Zustand with immutability.
- Language: Spanish (UI) for English learning context.

## Brand Identity
- **Logo**: Squircle icon with E&G intertwined.
- **Colors**: Coral Orange (#FF5E36), Electric Purple (#5D26C1).
- **Type**: Plus Jakarta Sans, Poppins, Inter.

## Tech Stack
- React 18, TypeScript, Tailwind CSS, Vite.
- Framer Motion, Lucide React, Recharts.
- Capacitor for Android compilation.
